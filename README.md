# Visinage: three design directions

Design prototypes for Visinage, an independent research, data and visual publication. Each direction has a homepage, the public radar and the opener of the lead piece, built on the same placeholder content.

Open `index.html` (or the GitHub Pages link for this repo) and tap a preview.

- `directions/01-instrument`: dark-first, the tick ring as hero, radar and mark
- `directions/02-objects`: light, toon-shaded 3D objects where the object is the chart
- `directions/03-poster`: big type, colour blocks, duotone photography

Every figure is demo data. Photographs are placeholders from Unsplash; see `assets/img/credits.json` for photographers.
